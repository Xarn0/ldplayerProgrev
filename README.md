# LDPlayer Warmup Master (Client GUI & Worker)

Автономное приложение для управления прогревом аккаунтов Instagram на ферме эмуляторов LDPlayer с автоматической отправкой телеметрии в центральную Контент-машину (`app.prime-trans.online` / `voxorl-panel`).

---

## 🚀 Возможности

1. **Автоопределение аккаунтов на устройстве:**
   - Читает системные хранилища `/data/data/com.instagram.android/shared_prefs/` через ADB root shell;
   - Автоматически выводит список уже залогиненных аккаунтов прямо в интерфейсе.
2. **Гибкая настройка нишевых тегов:**
   - Для каждого аккаунта можно назначить ключевые поисковые слова и теги (например: `real estate, dubai, luxury, investment`), по которым бот будет искать и взаимодействовать с контентом.
3. **Безопасность (NekoBox VPN Guard):**
   - Перед каждым действием проверяется сетевой интерфейс `tun0`. Если VPN отключился — сессия немедленно останавливается, защищая реальный IP.
4. **Бесшовная передача в веб-панель:**
   - Все сессии, просмотры Reels, лайки, оставленные комментарии и чекпоинты передаются в `http://45.39.60.233:8098` и отображаются в карточках аккаунтов в панели Контент-машины.

---

## 🛠️ Установка и запуск на ферме

### Требования
- Windows 10/11 x64
- Установленный эмулятор LDPlayer 9 / 14 (по умолчанию: `C:\LDPlayer\LDPlayer14` или `C:\LDPlayer\LDPlayer9`)
- Python 3.10+ (с флагом `Add Python to PATH`)
- NekoBox / WireGuard / Прокси с виртуальным туннелем `tun0`

### Быстрый старт
1. Запустите эмулятор LDPlayer и включите в его настройках **Root-права** и **Отладку по ADB**.
2. В папке репозитория запустите `START_APP.bat` (или выполните `python server.py`).
3. В браузере автоматически откроется панель управления: `http://localhost:8099`.
4. Нажмите кнопку **«🔍 Сканировать Instagram»** — приложение считает аккаунты.
5. Укажите нужные нишевые теги для каждого аккаунта и нажмите **«💾 Сохранить теги»**.
6. Нажмите **«🚀 Запустить прогрев выбранных»**.

## 📱 Запуск в виде Android APK на самом эмуляторе

Приложение построено на базе универсального PWA/WebView:
- Внутри браузера Android (в самом LDPlayer) откройте `http://10.0.2.2:8099` (или локальный IP вашей машины в локальной сети `http://192.168.x.x:8099`).
- Нажмите «Добавить на главный экран» (Install PWA) либо упакуйте каталог `web/` через Cordova / Capacitor / WebView wrapper APK (`npx @capacitor/cli add android`).
